📚 Lección: Números Complejos

1. Situación Cotidiana

Imagina que estás diseñando el mapa de un videojuego o analizando la corriente en un circuito de tu casa. Si caminas hacia adelante o atrás, estás en una dimensión recta (números reales). Pero, ¿qué pasa si necesitas representar rotaciones de 90° sin salir del sistema o describir ondas de corriente alterna donde la tensión y la corriente no van en fase? Los números reales no bastan para calcular la raíz de una resistencia negativa en circuitos; ahí nacen los números complejos como un plano bidimensional perfecto para gobernar giros y oscilaciones.

2. Conceptos Previos Necesarios

Para comprender este tema, debemos recordar cómo operan las raíces con números negativos y la ley de los signos:

x2 = -1  ⇒  x = √-1

En los números reales (R), ningún número elevado al cuadrado da negativo. Por ende, se define la unidad imaginaria (i) como:

i = √-1   ⇒   i2 = -1

3. Lenguaje Técnico y Definición Formal

Un Número Complejo es una entidad matemática expresada de la forma binómica z = a + bi, donde:

  • a = Re(z): Parte real (número real puro).
  • b = Im(z): Parte imaginaria (coeficiente real de i).

Clasificación de los Números Complejos

Tipo Condición Ejemplo
Real Puro b = 0 z = 7
Imaginario Puro a = 0, b ≠ 0 z = -5i
Complejo Mixto a ≠ 0, b ≠ 0 z = 3 + 4i

4. Formalización y Propiedades

Dados z1 = a + bi y z2 = c + di:

  • Suma/Resta: (a ± c) + (b ± d)i
  • Multiplicación: (a·c - b·d) + (a·d + b·c)i
  • Conjugado (z̄): a - bi (invierte el signo de la parte imaginaria).
  • Módulo (|z|): √a2 + b2 (distancia al origen).

5. Simulador Interactivo en el Plano Argand

Ajusta la parte real (a) e imaginaria (b) para observar el vector z = a + bi y su módulo:

z = 3 + 4i | |z| = 5.00

6. Ejemplos Resueltos Curados

Ejemplo 1 (Básico): Suma Directa
Enunciado: Dados z1 = 4 + 3i y z2 = -2 + 5i, calcula z1 + z2.
Solución paso a paso:
1. Agrupar partes reales: 4 + (-2) = 2.
2. Agrupar partes imaginarias: 3i + 5i = 8i.
Resultado: 2 + 8i
Ejemplo 2 (Intermedio): Multiplicación de Complejos
Enunciado: Multiplica z1 = (3 + 2i) por z2 = (1 - 4i).
Solución paso a paso:
1. Aplicar propiedad distributiva: 3·1 + 3·(-4i) + 2i·1 + 2i·(-4i).
2. Evaluar productos: 3 - 12i + 2i - 8i2.
3. Sustituir i2 = -1: 3 - 10i - 8(-1) = 3 - 10i + 8.
Resultado: 11 - 10i
Ejemplo 3 (Avanzado): División y Conjugado
Enunciado: Calcula la división z = (4 + 2i) / (1 + i).
Solución paso a paso:
1. Multiplicar numerador y denominador por el conjugado del denominador (1 - i):
   [(4 + 2i)(1 - i)] / [(1 + i)(1 - i)]
2. Numerador: 4 - 4i + 2i - 2i2 = 4 - 2i + 2 = 6 - 2i.
3. Denominador: 12 - i2 = 1 - (-1) = 2.
4. Dividir cada término entre 2: (6/2) - (2/2)i = 3 - i.
Resultado: 3 - i
